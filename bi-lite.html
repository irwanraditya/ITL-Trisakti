Cara memakai BI Lite

BI Lite meniru alur kerja Power BI dan Tableau dalam versi ringan. Semua data fiktif dan berjalan di browser Anda; tidak ada yang dikirim ke server.

Membuat visual

  1. Klik + Visual, lalu pilih jenis grafik di tab Visual.
  2. Klik atau seret kolom dari daftar Data ke kotak Sumbu (kategori), Legenda (warna), atau Nilai (angka).
  3. Ubah cara hitung di kotak Nilai: Jumlah, Rata-rata, Median, Min, Maks, Hitung, Hitung unik, atau % Ya (untuk kolom Ya/Tidak seperti Tepat_Waktu = OTD).

Menyaring

  • Filter silang: klik batang, irisan, titik, atau baris tabel. Visual lain dari tabel yang sama ikut tersaring. Hapus lewat tanda × di atas kanvas.
  • Slicer: visual daftar centang untuk menyaring seluruh halaman.
  • Tab Filter: filter untuk visual terpilih atau seluruh halaman, berupa daftar nilai atau rentang angka/tanggal.

Kolom tanggal

Setiap kolom tanggal punya hierarki: Tahun, Semester, Kuartal, Bulan, Minggu, dan Hari. Pakai Bulan untuk tren bulanan.

Tabel dan relasi

Tabel Kiriman (11.155 baris) sudah digabung dengan Pelanggan lewat Kode_Pelanggan (Segmen_Pelanggan, Jenis_Tarif, Diskon_Pelanggan). Tabel lain: Pelanggan, Armada, Gudang, Terminal. Satu visual memakai satu tabel. Arti setiap kolom tampil saat kursor diarahkan ke nama kolom; tabel lengkapnya ada di tampilan Data.

Menyimpan

Dashboard tersimpan otomatis di browser ini. Pakai Simpan berkas untuk memindahkannya ke perangkat lain atau mengumpulkannya ke dosen, lalu Buka berkas untuk memuatnya kembali.

Padanan istilah

  • Power BI: Visualizations = tab Visual · Fields = Data · Filters = tab Filter · Page = Halaman.
  • Tableau: Columns/Rows = Sumbu/Nilai · Marks Color = Legenda · Worksheet = visual · Dashboard = halaman.
